# Update your portfolio

Read **[EDITING-GUIDE.txt](EDITING-GUIDE.txt)** for the complete guide for this edition.

Open **[editor.html](editor.html)** to update projects, profile, achievements, certificates, education and skills using forms. Export `data.js`, replace it in your source, and commit it with new assets to GitHub.

For the first upgrade from the earlier edition, upload all changed site files, including `content.js`, `motion.js` and `editor-content.js`. Subsequent content edits normally only change `data.js`.

See **[README.md](README.md)** for the source file map.
