# Sathwik — Curiosity, Engineered.

**Open START-HERE.html first.** It explains local preview, future updates, cover images, and static-host deployment.

- Open index.html for the portfolio.
- Open editor.html to add, edit, reorder, and export projects.
- Replace data.js with your export, then redeploy this folder.
- Keep assets/ with index.html. No installation, build command, API keys, or backend are required.

Includes a short cinematic entrance, original sculptural artwork, manual featured-project showcase, project case studies, search, local shortlist, quick introduction, responsive layout, and motion controls. Artwork and fonts require no external CDN. Project artwork is conceptual rather than an app screenshot.

The editor writes browser-local drafts and downloads data.js; it does not publish to your host. Upload/redeploy yourself, or attach data.js in the original ChatGPT conversation and ask to update the existing site.

All project data is in data.js. The opening copy and biography are in index.html. Styles and interactions are in style.css and script.js. Detailed schema: UPDATE-GUIDE.md.

Designed for current desktop/mobile Chrome, Edge, Firefox, and Safari. Local content checks and logic tests pass. Device/browser visual and frame-rate testing remains necessary because the build environment had no preview service.
